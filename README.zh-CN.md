<h1 align="center">AgentTV</h1>

<p align="center">看见 agent 的进展，留住下一步的想法。</p>

<p align="center"><a href="README.md">English</a> · 简体中文</p>

AgentTV 希望提供一个工作区，让你查看 AI agent 会话的进展，也能随时记录新想法，不必改变原有的 agent 使用方式。

## 为什么做 AgentTV？

同时使用多个 agent 时，你需要在不同工具之间切换，确认进展、寻找结果，还要记住接下来做什么。AgentTV 希望通过两个相互关联的工作区，把这些事情放在一起：

- **Preview** — 按项目查看进展、查找会话。需要你处理的结果会一直保留提示，直到你明确标记已处理。
- **Record** — 随时写下 idea、TODO 和 prompt，之后再整理，准备好后复制到选定的 agent。即使没有 agent 运行，也能独立使用。

继续使用你熟悉的 agent 工具。AgentTV 的设计目标是观察进展、保留可搜索的历史；是否发送、发送什么，仍由你决定。

## 项目仍在早期

AgentTV 目前处于设计阶段，尚无可运行的应用。首批计划接入 pi、Codex CLI 与 desktop、Kimi Code 和 Claude Code；这些是目标，不代表已经支持。
