开发 Harness首轮开发计划开发计划模板
复制为当前任务的 HTML 计划后填写

计划名称：说明完成后能做什么

填写创建与更新日期，将 agenttv:plan-status 改为 planned、active、complete 或 blocked。状态反映实际进展，用户要求暂停时在正文记录。

本页内容
  • 目标与范围
  • 进度与步骤
  • 发现与决定
  • 验证与验收
  • 重试与恢复
  • 结果与剩余工作

目标与范围

说明用户会获得什么、为什么需要这次修改，以及本轮处理哪些内容。列出当前任务相关源码与设计章节，解释继续工作必需的背景。

进度与步骤

按可以单独验证的结果划分步骤，标注未开始、进行中或完成，记录实际日期。为每步写明修改位置、依赖和完成后能观察到的变化。

发现与决定

记录影响实现的事实、决定、原因和日期。外部接口写明实际版本；改变方向时同时更新步骤与验收内容。

验证与验收

列出相关场景 ID、实际可运行的命令、输入和预期结果。记录已执行检查的日期与结果；尚未提供的命令标明待实现。

重试与恢复

说明临时数据、实例与资源放在哪里，如何安全重跑和清理。修改保存格式时说明迁移、备份和失败后的恢复方式。

结果与剩余工作

阶段结束时填写已经实现的行为、可查看的结果和实际验证范围。未完成内容与下一步保留明确记录，完成后将计划状态更新为 complete。
